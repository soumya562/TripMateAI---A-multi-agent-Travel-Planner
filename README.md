# TripMateAI---A-multi-agent-Travel-Planner
A multi-agent Travel Planner using LangGraph

# how to run ?

1. create the virtual environment
command : conda create -n travel python=3.11 -y

2. Activate the environment
command : conda activate travel

3. Install the requirements
pip install -r requirements.txt

# Install pgAdmin in local machine and setup postgres on render cloud
we will connect our render cloud postgres instance from local pgAdmin to view the database.
